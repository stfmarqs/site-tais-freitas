# Landing Page & Cartão de Visita Digital — Dra. Taís Freitas (OAB/MT 23.396)

Landing Page moderna, de alta performance e engenharia de conversão consultiva desenvolvida especificamente para a **Dra. Taís Freitas**, com foco em **Direito Previdenciário (INSS)** e **Direito do Consumidor (Direito Aéreo e Fraudes Bancárias)**.

---

## 🏛️ Destaques da Arquitetura & Design

- **Identidade Visual Fiel ao Manual de Marca:**
  - Marrom Carvão (*Pantone 411 C - `#3B3732`*)
  - Laranja Pastel / Terracota (*Pantone 1565 C - `#FDBA74` / `#D97736`*)
  - Cinza Claro e Off-white (*Pantone Cool Gray 1 C - `#FAF8F5` / `#F1F1F1`*)
  - Tipografias: *Playfair Display* (autoridade serifada), *Zilla Slab* (tipografia complementar oficial) e *Poppins* (interface limpa).
- **Sem clichês jurídicos:** Total ausência de martelos, colunas gregas ou livros empoeirados. Design editorial contemporâneo com cartões modulares e fotografia documental autêntica.
- **Engenharia de Conversão Consultiva:**
  - **Simulador de Enquadramento Prévio:** Ferramenta interativa de triagem em 3 etapas (*Pitta & Baione / Fight4Vets*) que qualifica o cliente e pré-preenche a mensagem do WhatsApp com o diagnóstico exato.
  - **Cartão de Visita Digital Integrado:** Modal com geração de QR Code dinâmico para leitura presencial e download automático do contato em formato `.vcf` (salva na agenda do iPhone/Android em 1 clique).
  - **Bento Grid de Especialidades:** Seletor ágil entre Previdenciário e Consumidor, com CTAs contextuais por matéria.
  - **Visual Law em 3 Etapas:** Explicação didática da jornada do constituinte sem jargões jurídicos.
- **Conformidade Ética Absoluta (Provimento 205/2021 da OAB):**
  - Publicidade passiva e consultiva.
  - Ausência de termos mercantilistas ("contrate já", "ganhe sua causa", "grátis").
  - Identificação clara de OAB/MT 23.396 e ressalvas deontológicas no rodapé.

## 🚀 Como Executar Localmente

No terminal, dentro da pasta do projeto:

```bash
# 1. Acessar a pasta
cd C:\projetos\tais-freitas-adv

# 2. Instalar as dependências (já instaladas)
npm install

# 3. Iniciar o servidor de desenvolvimento
npm run dev
```

O site estará disponível em `http://localhost:5173`.

---

## 📦 Como Gerar a Versão de Produção (Build)

```bash
npm run build
```

Os arquivos estáticos otimizados serão gerados na pasta `dist/`.

### 🌐 Onde hospedar (Custo Zero ou Próprio):
- **Vercel / Netlify / Cloudflare Pages / GitHub Pages:** Basta conectar o repositório ou fazer upload da pasta `dist/`.
- **Hospedagem cPanel / HostGator / KingHost / Locaweb:** Basta copiar o conteúdo da pasta `dist/` para a pasta `public_html/`.
- Não exige banco de dados nem servidor backend — carregamento instantâneo em menos de 1 segundo em qualquer conexão móvel.
